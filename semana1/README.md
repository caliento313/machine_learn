# 📘 Aula de Machine Learning — Teo Me Why

Este repositório contém materiais, anotações e códigos desenvolvidos durante a **aula de Machine Learning** apresentada por **Teo Me Why**. O objetivo é registrar os principais conceitos, exemplos práticos e aprendizados abordados na aula, servindo como material de estudo e referência futura.

---

## 🎯 Objetivo da Aula

Introduzir os fundamentos de **Machine Learning**, explicando conceitos teóricos essenciais e demonstrando como aplicá-los na prática usando Python e bibliotecas populares de ciência de dados.

---

## 🧠 Conteúdos Abordados

* O que é Machine Learning
* Tipos de aprendizado:

  * Aprendizado Supervisionado
  * Aprendizado Não Supervisionado
  * (Introdução ao) Aprendizado por Reforço
* Diferença entre **features**, **target** e **modelo**
* Conceito de treino e teste
* Overfitting e Underfitting
* Métricas de avaliação
* Pipeline básico de Machine Learning

---

## 🛠️ Tecnologias e Bibliotecas

* Python 3
* Pandas
* NumPy
* Scikit-learn
* Matplotlib / Seaborn (para visualização, se aplicável)

---

## 📌 Principais Aprendizados

* Machine Learning é mais sobre **processo e perguntas certas** do que apenas algoritmos
* A qualidade dos dados impacta diretamente o desempenho do modelo
* Separar corretamente dados de treino e teste é essencial
* Métricas devem ser escolhidas de acordo com o problema
